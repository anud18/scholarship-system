# Step 1
進到 GitHub Action 網站
https://github.com/NYCUITSC/naass/actions

# Step 2
選擇要還原或啟動 Test 還是 Production 環境
點擊對應的 workflow

`Deploy to Production`

`Deploy to Test`

<img width="545" height="618" alt="GitHub Actions workflow 清單，含 Deploy to Production 與 Deploy to Test" src="images/restore-system-01-select-workflow.png" />

# Step 3
點擊 Run Workflow
<img width="1494" height="582" alt="Deploy workflow 頁面，展開 Run workflow 表單" src="images/restore-system-02-run-workflow.png" />

選取要還原到或者是啟動哪一個版本

<img width="189" height="89" alt="Run workflow 表單中的 Use workflow from / Branch 選單" src="images/restore-system-03-use-workflow-from.png" />

<img width="328" height="577" alt="Select ref 下拉選單的 Tags 版本清單" src="images/restore-system-04-select-ref-tags.png" />

以及在 `Upstream image tag to deploy (e.g. main-2c2b89d6 or v1.2.3). Defaults to latest.` 輸入版本名稱
像是 `v1.0.0`
接著點擊綠色的 `Run workflow`
